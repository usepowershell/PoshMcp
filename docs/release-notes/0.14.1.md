# PoshMcp v0.14.1 Release Notes

**Release Date:** May 16, 2026

## Summary

Patch release adding per-tool import source tracking to the doctor and runtime diagnostics paths. Runtime tools like `get_configuration_status` and troubleshooting now correctly report which config file each tool came from, instead of "unknown".

## What's New

### Import source tracker interface (issue #272, PR #276)

- New `IToolImportSourceTracker` interface for per-tool import source attribution
- `FileSystemToolImportSourceTracker` implementation tracks which config file each tool was loaded from
- Refactored `McpToolFactoryV2` to accept the tracker via DI
- Threaded tracker through all code paths including `DoctorService.BuildDoctorReportFromConfig()` runtime surfaces
- Runtime `get_configuration_status` and troubleshooting tools now correctly report tool source

### Tests

- Added parity tests between CLI doctor and runtime status/troubleshooting paths
- Verified tracker threading through all execution paths

## Documentation

- Updated Spec 011 references to link issue #272
- Tutorial series for stdio, docker, and API key auth (#273, #274, #275)

## Breaking Changes

None.

## Upgrade Notes

**Drop-in upgrade.** No configuration changes required.
