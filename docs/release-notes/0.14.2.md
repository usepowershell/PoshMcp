# PoshMcp v0.14.2 Release Notes

**Release Date:** May 17, 2026

## Summary

Security patch hardening all log sinks against CWE-117 (log forging). Applied `LogSanitizer.Scrub()` to every user-controlled or environment-controlled value that flows into structured log statements.

## What's Changed

### Log forging remediation (issue #277, PR #278)

- Scrubbed all 24 CodeQL `cs/log-forging` alert sites across `PowerShellAssemblyGenerator.cs`, `AuthenticationServiceExtensions.cs`, and `LoggerExtensions.cs`
- Comprehensive hardening pass: also scrubbed additional log sinks in `PowerShellAssemblyGenerator.cs` that weren't flagged by CodeQL but follow the same CWE-117 pattern (command names, property names, filter scripts, exception messages, type names)
- All sanitization uses the existing `LogSanitizer.Scrub()` utility (escapes CR/LF and control chars, truncates overlong values)

## Breaking Changes

None.

## Upgrade Notes

**Drop-in upgrade.** No configuration changes required. This release only affects log output formatting — sanitized values will show escaped control characters instead of raw values.
